La présentation est sous forme de site Quarto.
Vous pouvez exécuter les commandes suivantes pour lancer le site :
    `py -m venv .venv`
    `.venv\Scripts\activate`
    `pip install -r requirements.txt`

Puis, déployez le site Quarto
    `quarto preview`

Toute l'étude est contenue dans un notebook : /website/code/version_finale/combine.ipynb
Tous les autres fichiers sont soit des fichiers de quarto soit des fichiers brouillons de travail.
